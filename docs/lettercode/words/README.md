# LetterCode English dictionary

The Angular and Flutter versions share 922 curated common targets and 15,924 unique accepted five-letter ASCII guesses. The accepted list contains all 15,921 five-letter entries from dwyl/english-words plus three legacy entries. It includes rare words and does not claim to contain every English word.

Provenance: dwyl/english-words, revision 20f5cc9b3f0ccc8ce45d814c532b7c2031bba31c, words_alpha.txt. See sources/sources.json and sources/dwyl-LICENSE.md.

The checked-in JSON is copied from lettercode_game/assets/words/en_sample.json. Its arrays are also exported by src/app/lettercode/sample-words.ts for synchronous engine startup. Keep both files synchronized. Targets are curated common words from the accepted list; Standard filters targets to words with five distinct letters, while Expert uses the full target list.
